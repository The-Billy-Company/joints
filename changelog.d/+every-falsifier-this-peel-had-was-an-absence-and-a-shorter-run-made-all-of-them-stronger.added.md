`Cold.canopy` - every span round 1 built a node over, and the first falsifier here
that a weak run cannot make stronger.

Both peels answered "is this cold wall real" with an absence. Warm says *I never
met it*, which is exactly as convincing as its budget is short: swift's run reached
byte 2,904 of 28,467 and would have acquitted the other 25,563 for free. `Warm.frontier`
bounds that honestly but cannot change its shape - the failure mode still runs the
same direction as the headline.

A node is the opposite. If round 1, reading the file nobody cut, **consumed a token
at byte B**, it did not refuse at B, so a later round refusing at B is refusing in
text the peel made. A shorter run can fail to find that evidence; it cannot
fabricate it. Round 1 was already being parsed with `--ranges --all`, so the spans
cost nothing, and only round 1's are kept - every later round's offsets are into a
suffix the loop cut, and rebasing them would be arithmetic over a document nobody
wrote.

**It convicts four walls corpus-wide, and the abstention is the finding.** Round
1's forest on `Chunked.swift` covers `[1477, 1492)` and jumps to `[1507, 3501)` - a
fifteen-byte hole over exactly the `)`, `}`, `}`, `}` the cold peel walls on. The
whole-file parse built nothing there either; it *mended*, and `stamp.outcome`
reports a mended parse's first stop and nothing else. So the cold peel is not
inventing wall **locations** - the bytes it stops at are bytes the whole-file parse
also failed to build over. What a fragment manufactures is the **attribution**: the
terminal, the state, and therefore the owner, the family and the price.

Which names the one number missing from this repository: **a whole-file parse that
enumerates its mend sites.** `outliner parse` gives the first stop, `--ranges --all`
gives a forest that shows a hole without saying what refused in it, and `amend` takes
an edit and answers a different question. Every instrument in `tool/` is downstream
of that verdict, so cold, warm and canopy are three ways of working around one
absence. 18,146 bytes of the board stay `untested` until it exists, which is a worse
report than either peel would give and the only one either can support.

The canopy is also the instrument this lane trusts least, and it passed its own
check. A node in a *mended* forest is the parser choosing where to resume, so "a
node begins at B" is nearly but not exactly "the parse did not refuse at B" - and on
verilog, mending 2,109 times, the two are currently indistinguishable. It errs
toward calling a wall the instrument's, which is the flattering direction for a
re-price whose headline is *most of this board is the instrument*. Kept to four
convictions for that reason.
