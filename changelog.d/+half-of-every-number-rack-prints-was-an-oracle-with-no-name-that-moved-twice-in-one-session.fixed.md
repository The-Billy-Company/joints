`rack.py` stamped fourteen fields about the run and **all fourteen were about
joints**. The oracle is the other half of every number it prints and carried
no tree-sitter version, no digest, no seat. A sibling lane caught what that
costs: **scala read 1,278 crooked in one run and 9,087 in the next — same pin,
same unedited script, stamp byte-identical.** Three oracle libraries under
`.local/differential/` had been rebuilt mid-session by other lanes, and nothing
in the tree recorded it. Every rack figure quoted before today is
unreproducible, not because anyone was careless but because the instrument had
no field to be careless in.

`tool/attest.py` seats the oracle. It digests the **sources** each grammar is
built from rather than the built library, groups grammars by digest under a tag,
and `rack.py` and `absent.py` both call `attest.consult` on start and print
`attest.told()` on exit, so a seat rides every table either one emits. Runs
against the shared tree say `UNPINNED — this is the shared tree four lanes write
to` rather than pretending otherwise.

Sources and not the library, because `attest.py verify` measures this machine
and the library cannot carry the identity:

| claim | measured |
| --- | --- |
| one grammar's oracle is several different files at once | 28 of 29 |
| …and divergence is not a parser: verilog differs in | 0.0003% of bytes |
| …nor is it cosmetic: css differs in | 62.3% of bytes |
| a library older than its sources — the CLI's rebuild trigger | 23 of 29 |

Rows two and three are the argument. A library digest calls a plain rebuild of
the same parser a change and cannot tell that apart from the case where the tree
genuinely holds two oracles at once — which is twenty-eight of twenty-nine
grammars right now. Two of those four claims began as stronger sentences that
the measurement refused, and the refusals are in the file: an early version
asserted the difference was "a build id, not a parser", which css falsified at
62.3% of its bytes.

tree-sitter 0.26.11, thirty grammars.
