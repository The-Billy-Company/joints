`standing.py --against` refuses two new shapes, at exit 4, in the same place it
already refuses a cross-tree diff — before any delta is printed, because a
reader who has seen `crooked 0 → 0` has already formed the claim the refusal
would have stopped.

**square-silent** — no board on either side read a single square byte. Whatever
moved below, both arms are outliner's own words about its own forest, and a
change can leave `built` untouched while moving every leaf to a different
parent. **one-eyed** — one side read a square and the other did not. Worse and
quieter: the delta between a measurement and a silence is neither of them, and
it prints as an enormous improvement. One retained pair on this disk is exactly
that, an arm at 311,540 square against a control whose thirty verdicts were all
refused as stale.

The square a board *accepted* is what counts, summed off the rows with `graded`
in `read`/`part` rather than off the cache, because a board holding thirty
verdicts it refused has read no square at all and that is the case worth
catching.

`--unjudged` declares the narrow reading rather than buying silence: the label
prints beside the numbers as `UNJUDGED (declared)` and travels with them into
whatever reads the run next, which is what the previous audit had to reconstruct
three lanes later off an empty column.

Scored on four boards built for it:

    blind vs blind                exit 4   NOT A CLAIM ABOUT AGREEMENT
    blind vs blind --unjudged     exit 1   UNJUDGED (declared)
    sighted vs blind (one-eyed)   exit 4   NOT A CLAIM ABOUT AGREEMENT
    sighted vs sighted            exit 1   silent
    --twice, one binary           exit 0   silent

The last row is the one that had to be right. A stability run asks whether a
board is reproducible and makes no claim about a second parser, so the
precondition is the one `comparable` already uses to demote `subject`: two arms
and two binaries. A gate that reddened `--twice` is a gate lanes learn to pass.
