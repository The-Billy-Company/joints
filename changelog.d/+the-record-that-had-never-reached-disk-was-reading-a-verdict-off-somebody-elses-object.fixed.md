`budge` admits an object to a record when the record's **required** columns are
a subset of the object's keys, and nothing charges a record for the keys it
cannot explain. `walls.Priced` declares seven columns of which four are
required - `cost hits kind who` - and those four sit on every stale
`owners.Wall` board under `.local/strand/` and `.local/reprice/`, written
before `Wall` grew `roofed`. `Priced` is the only record in the tree those
objects fit, so it took all 3,507 of them, explaining four keys of fourteen.

Which produced both halves of the failure this instrument is named for. It
reported `walls.Priced.roofed` **`silent/open`** - a finding, on the board, in
the fourteen - for a column of a record that **has never been written to disk
at all**: `Priced` goes out as a positional tuple inside a `Depth`, never as a
JSON object. And it reported the six columns beside it **`budged`** - green,
alive, cleared - on values belonging to a different record entirely. Six green
rows resting on somebody else's evidence is precisely the vacuous clearance
`budge` exists to name, and `budge` was committing it.

So `harvest` now counts, per record, the objects that carried **every**
declared column - an object that can only be that record's own rendering. A
record charged objects and never handed one of its own reads
**`unseen/adrift`** on every column: the sweep says it has no opinion, which is
true, instead of reading a verdict off a foreigner. The looseness stays where
it earns its keep - a board written before a column existed is still read, and
still contributes `silent` - because tightening to "every declared field" would
have thrown away the honest partials too: `rack.Run`, `standing.Row`,
`walls.Depth`, `attest.Oracle`, `still.Witness` and `walls.Warm` all carry
thousands of complete objects **and** older partial ones. `walls.Priced` was
the only record in the tree with zero complete objects, so the collateral of
the rule is exactly the one record it was written for.

Falsified in `budge verify`: nineteen `field.Press` columns cut down to the two
required ones read 18 of 18 `unseen/adrift` and 0 red, and the same rows
written whole read real verdicts. The bug this sweep was built for -
`still.Witness.oracles` filled by the retired stem rule - still reads
`void/open` and still reddens exactly one field of eighteen, so the new
tolerance cannot reach it.

Board: **13 red → 12**, and six false-green rows retired with the red one.
