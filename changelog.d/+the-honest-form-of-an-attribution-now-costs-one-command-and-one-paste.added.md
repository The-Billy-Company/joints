A gate that refuses a page and offers no cheap way to satisfy it is a gate
somebody turns off. `sighting.py --gate` now refuses a page that quotes a
measured figure and names no tree; `standing.py --cite` is the other half.

```
$ python3 tool/standing.py --cite
joints `e51716d6c` · tree `61c93c367` (live) · **no oracle** — joints's own words
```

One line, markdown, **110 ms**, and it runs no survey. That is the whole design
constraint: an attribution priced at a board is an attribution priced at thirty
seconds, and a lane mid-sentence will not pay it. `still.Witness.cite()` reads
what `still.take` already records - the binary that pressed, the tree it was
built from, whether an oracle was in the room and how many - and renders the
three fields that make a figure re-findable, dropping the seven that make
`line()` a terminal diagnostic rather than a quotation.

It inherits yesterday's discipline rather than restating it. A board that never
asked an oracle cannot mint an attribution that implies it did: the line reads
**no oracle — joints's own words**, in bold, in the same sentence as the
digest, which is the `damage 0` fix arriving in prose.

**What it does not do, and cannot.** It does not prove the figure beside it came
from this world. A lane can paste a fresh `--cite` next to a number copied off a
stale board and nothing on this tree will notice - the gate checks that a digest
is *present*, never that it is the *right* one. Binding a typed number to a
stamp is not reachable by any gate, because the number was typed. What this
removes is the excuse: the honest form now costs one command and one paste, and
the dishonest form costs a deliberate act rather than a moment's laziness. See
`research/joinery/consort/RESULT-11-quotation.md` for why the enforcement half
is a negative result.
