`standing.audit()` computes `soft` — the share of crooked bytes that is only
extras placement, where a comment hangs rather than a misreading — and subtracts
it from `crooked` so the headline charge quotes 52,226 and not 60,825. It drew
that sample from `rack.widest()`, which returns the widest runs *of each kind*,
`unframed` among them. So the sample was taken over `askew + racked + unframed`
and subtracted from `askew + racked`.

An `unframed` run qualifies as soft whenever the frame we failed to build is
named `comment`, which is to say: the name of the node outliner never built was
being used to excuse not building it. The test that fires is `w.theirs in was` —
tree-sitter built a comment, we built nothing, and nothing is what got the
discount. `rack.widest`'s own docstring predicts this, and the other two copies
of the soft rule in this tree never had it: `rack.soft` files an unframed run's
blank share as `hollow` and subtracts it from nothing, and `flag/spans.py`
softens a byte only when that byte's own class is already guilty. `standing.py`
was the third copy and the only drifted one.

The sample is now restricted to the kinds `crooked` is made of, which is repair
1 of the two the handoff left open. Repair 2 — keep the wide sample and subtract
its unframed share from `unframed` instead — is not merely unchosen: it is repair
1 plus an unargued discount on a second column, it puts `standing.py` at odds
with both other copies rather than back in step with them, and it shrinks the
total charge `crooked + unframed` by the overdraw where repair 1 moves the
overdraw back where it came from and leaves the total exactly where it was. It
also collides with the lane reclassifying bytes into `unframed` this hour, who
would find every byte they moved arriving pre-discounted.

Six rows of the base board were understated and are now repriced, all upward:
haskell 1,357 → 2,065, ocaml 2,083 → 2,113, cpp 631 → 652, swift 8,740 → 8,754,
sql 176 → 179, julia 156 → 158. Corpus `crooked` rises 51,448 → 52,226 and `soft`
falls 9,377 → 8,599, exactly equal and opposite; `square`, `unframed`,
`unaudited` and `built` move on zero of thirty rows, so `trued` and every
conclusion resting on it stand unchanged. Each row lands on `borrow.py`'s
`restricted` column to the byte. haskell was missing 34% of its own charge and
`widest by CROOKED` now prints it fifth, ahead of scala.

The negative was only the tail. On the arm that read `crooked −8,669`, the
shipped rule subtracted the whole of `soft` from `seen.crooked`, so that arm's
true crooked is `−8,669 + 9,687 = 1,018` — a bucket borrowing eight and a half
times the balance it was drawing from. Under the repair `soft` is a subset-sum
of the very runs that total `seen.crooked`, asserted per row against
`rack.Seen.crooked`, so `crooked − soft < 0` stopped being a number this board
can produce rather than one it happens not to.
