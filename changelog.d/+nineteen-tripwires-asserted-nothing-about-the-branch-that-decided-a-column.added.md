A column could be 97.9% mislabelled with every gate green, because not one of the
nineteen assertions in `rack.py verify` mentioned the branch that decided it. A
gate that passes because it never looked is indistinguishable from one that
looked and approved.

Eight assertions now do, and they are asked of the **corpus** rather than of a
named row — the lesson the `engulf` tripwire paid for this morning, when a press
change let elixir build its `do_block` and the falsifier failed for a reason that
had nothing to do with what it guarded. **A red pinned to a named row is a red a
sibling can delete.**

Two columns exist to make the claim checkable. **`shade`** is the disputed
population — bytes under a frame we never built, with our own structure
underneath and none of the oracle's — and it does **not** move with the price,
which is the whole point. **`shelter`** is how many of them the active price still
files `unwindowed`, so the assertion is `shelter == 0` and it is a statement about
the shipped rule rather than about any grammar. Anti-vacuity rides beside it: 26
bytes over three rows survive as genuine `unwindowed`, so the column was narrowed
rather than abolished.

Proven by breaking it. `verify --price=sheltered` restores the retired branch
order and **exactly one row goes red**, naming all nine grammars and the exact
count, while all twenty-seven others — including every pre-existing one — stay
green:

```text
FAIL  no byte reads as silence while standing under a frame we never built:
      1486 sheltered of 1486 — haskell 998, verilog 395, cpp 38, ocaml 27,
      swift 14, julia 8, sql 3, ruby 2, bash 1. THE RETIRED BRANCH ORDER IS IN
      FORCE: `unwindowed` reads as the oracle's silence and is a charge.
```

**The other branches were audited for the same shape and one has it.** Of the
4,712 bytes the oracle could not adjudicate, **3,735 (79.3%) also stand under a
frame we never built** — verilog 3,617, sql 118, nothing else. It does not move,
and the reason is measured rather than argued: 100% of that overlap arrives
through the `ERROR` arms and **none** through *"the oracle has no node here"*. In
the `unwindowed` case the oracle's frame is its verdict; in the `ERROR` case the
oracle's own tree is damaged over the byte, so the frame is not evidence about
us, and the day `square`'s denominator includes bytes no oracle judged is the day
it stops meaning anything. So it is counted rather than moved, in the instrument
as **`mute`** rather than in a dossier a future lane rediscovers, and `verify`
asserts it is a subset of `unjudged` on every row and never a second charge for
the same byte.

`verify` holds 28 of 28.
