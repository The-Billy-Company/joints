A grammar's scanner is data now: a **customary**, pressed into the folio beside
the parse table and run by one engine, where tree-sitter runs a linked
`scanner.c` and this package ran a hand-written Zig hand per convention.

That exception was the ceiling. Every external terminal a grammar declares and
this binary has no hand for is `blind` - an honest wall, and for three hundred
imported grammars it was most of the wall. The roster of hands was already seven
kinds with eight discriminator fields between them, so the answer could not be
more hands: yaml alone declares 113 terminals and not one of them lexes.

The claim rung 0 tested is that a scanner's memory is two stacks and a register
bank, its decisions are a conjunction of tests over bytes, line facts, the parse
state's own permission set and those organs, and its effects are pushes, pops,
register writes and one emit. It is tested by reading eight `scanner.c` against
what each one's own `serialize` writes, since tree-sitter requires that to be
the whole carried state. The organ set closed there, confirmed independently by
four scanners that each keep a `{kind, width}` stack under a different name, and
rung 1 widened the algebra four times - `pass`, `nest`, `abstain`, `span k` -
each one a case the census had already recorded without naming who would execute
it. `research/customary/` is the dossier, kill conditions written before the
rungs ran.

Held so far: expressiveness at markdown's 10,568 answers and kotlin's 139, none
missing and none the parse table would not have asked for; and composition at
3,306 of 3,306 cut schedules over 551 files, which is the `O(log n)` edit's
actual proof and needs no parser. Six books are transcribed - haskell, kotlin,
markdown, scala, swift, yaml. Rungs 2, 3 and 5 (zero cost when absent as a
measurement, the tree-agreement board, and the speed claim) are not done, so
nothing here is switched on for a grammar that has no book.

**The state travels whole, and that is the part worth having.** tree-sitter asks
a scanner to serialize itself into at most 1024 bytes, and every one of the
eight loses something doing it - markdown truncates its open-block stack, html
its tag stack - so a resumed parse there is a scanner told an approximation of
where it was. The organs are a field of `outside.Carry`, which is what
`Scanner.Save` already was, so they ride the copy that already carried the
hands: fixed capacity, no pointer anywhere in it, and now a test that pins both
halves of the size rather than a header claiming "~1 KB" while `fence`'s tags
were twice that on their own. `Gather` keeps one per ring, so an edit inside a
heredoc or a blockquote resumes from the ring below it.

Nothing changes for a grammar without one. The organs fold into the progress
`shape` by `xor` and weigh exactly nothing untouched, so the word is identical to
the one it was before they existed - an equality rather than a hope - and the ask
pays one null check.

Provenance stays three-tiered and fail-closed, because a confidently wrong tree
is the one outcome this package holds to be worse than silence. **Derived** is
proven from the grammar's own declarations. **Transcribed** is a committed
customary, cohort-gated exactly as a troupe is: every part resolves or none of
them do. **Absent** is still `blind`, still a located wall, still
`inquest.awaited_external`. Where a hand and a customary could both answer, the
transcription wins, because it is a reading of the scanner the grammar actually
ships.

It costs folio v6. Three ordinals were reserved so three areas could land for
one bump, and this is the case a reservation could not cover: a *new* ordinal
lengthens the directory the reader checks positionally, so a v5 folio would have
refused as `FolioBadDirectory` - a true refusal wearing a misleading name. There
was nothing to reserve for a scanner, because until now the scanner was Zig.

`mint --customary P` names one, `$JOINTS_CUSTOMARY` points at a directory
searched as `<grammar>.json`, and `<stem>.customary.json` beside the
`grammar.json` is found without being asked for. A typed path that is missing
refuses; a derived one that is missing is the ordinary answer and says nothing.
The folio cache treats a customary as a third press input, on the same footing as
the binary and the grammar, so a folio pressed before its book existed re-mints
rather than reporting a speed win for a scanner it never ran.
