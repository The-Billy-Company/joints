Drift a re-judgement cannot express is written down instead of left red.
`verdicts.toml` had two verilog rows its own header called "left drifted on
purpose", and `abide` fails closed on any drift, so every press change since has
met a red gate naming the same two rows - which is how the `parameter` regression
stayed unattributed for thirteen pins. Neither row can be re-judged into anything
true: `[89368,89412)` lost a `parameter_declaration` tree-sitter never had, so
both sides read `—`, and the only `side` `consistent` would accept there is
`agree` - filing a live regression as two parsers concurring.

So such a row keeps its verdict as judged and gains a `[verdict.drifted]` note:
what both trees say now, the move named, when it was read. It reads `HELD` and
still counts toward nothing - a note is a record, not a rehabilitation.
`adjudicated` exits 1 on drift nobody has read, on a note whose drift has moved
again, on a note that misnames what it read, and on a note whose row no longer
drifts; `prove` drives all three negative, including dropping a note to confirm
the note is what holds the row.
